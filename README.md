# Utils — Codebase Summary

A personal collection of Linux CLI utility tools written in Python and Bash. No build system or test suite; each top-level directory is an independent, self-contained tool.

---

## Repository Layout

```
utils/
├── global_vars.py       # Shared path constants (INSTALL_DIR, DATA_DIR, CACHE_DIR)
├── init.py              # Bootstrap: creates install dirs and writes config.yaml
├── config.yaml          # Generated by init.py; stores resolved INSTALL_DIR / CACHE_DIR paths
├── open/                # Directory-alias navigation tool
└── scripts/             # Miscellaneous standalone scripts
```

---

## Bootstrap

**`global_vars.py`** defines three path constants used across all tools:
- `INSTALL_DIR` → `~/.local/opt/utils`
- `DATA_DIR` → `~/Code/data`
- `CACHE_DIR` → `INSTALL_DIR/.cache`

**`init.py`** must be run once before installing any tool. It:
1. Writes `INSTALL_DIR` and `CACHE_DIR` to `config.yaml` in the repo root.
2. Creates `INSTALL_DIR` and `CACHE_DIR` on disk.
3. Copies `global_vars.py` and `config.yaml` into `INSTALL_DIR` so installed tools can import them at runtime.

## Tool: `open/` — Directory Alias Navigation

**Purpose:** Manage named shortcuts to directories and quickly navigate to them in the file explorer or terminal.

### Files

| File | Role |
|---|---|
| `open/src/o.sh` | Bash entrypoint; installed as `o` (renamed during install) |
| `open/src/open.py` | Python backend; manages the alias store |
| `open/data/dirs.csv` | Alias database (TSV: `alias\tpath`, despite the `.csv` extension) |
| `open/data/help.txt` | Help text printed by `o -h` |
| `open/install.py` | Preferred installer |
| `open/install.sh` | Alternative installer (resets `dirs.csv` to repo copy — use carefully) |
| `open/uninstall.sh` | Currently empty |
| `open/update.sh` | Update helper |

### Commands

| Command | Effect |
|---|---|
| `o <alias>` | Open alias's directory in the file explorer (`xdg-open`) |
| `. o -t <alias>` | `cd` into the alias's directory (must be sourced) |
| `o <file>.pdf\|.txt\|.md` | Open file directly with `xdg-open` |
| `o .` / `o ..` | Open current / parent directory in file explorer |
| `o -a [-d<sep>] <alias>[,<path>]` | Add alias (defaults path to CWD; appends + sorts `dirs.csv`) |
| `o -af <alias>` | Force-add: remove existing entry then add new one |
| `o -r <alias>` | Remove a single alias |
| `o -br <file>` | Bulk-remove aliases listed one-per-line in `<file>` |
| `o -n <old> <new>` | Rename an alias |
| `o -s <keyword>` | Search aliases by keyword |
| `o -l` | List all aliases |
| `o -h` | Show help text |

### Install

`open/install.py` rsyncs `src/` to `INSTALL_DIR/open/src/`, renames `o.sh` → `o`, makes it executable, and idempotently appends `export PATH=…` to `~/.bashrc`.

`o.sh` reads `CACHE_DIR` from `INSTALL_DIR/config.yaml` at runtime, so `init.py` must run first.

## Tool: `scripts/` — Miscellaneous Scripts

**Purpose:** A grab-bag of standalone utility scripts installed to `INSTALL_DIR/scripts/src/` and added to `PATH`.

### Installer

`scripts/install.py` rsyncs `scripts/src/` to `INSTALL_DIR/scripts/src/`, `chmod 755`s all `.sh`/`.py` files, and idempotently appends the target directory to `PATH` in `~/.bashrc`.

### Scripts

#### `backup.py`
Backs up personal configuration files to `DATA_DIR/configs/`:
- VS Code `keybindings.json`, `settings.json`, and `snippets/` → `DATA_DIR/configs/vscode/`
- `open`'s `dirs.csv` alias database → `DATA_DIR/open/`

#### `maketex.sh`
Compiles a LaTeX project to PDF:
- Takes an optional `.tex` filename argument; if omitted, auto-detects the sole `.tex` file in the current directory.
- Runs `latexmk -pdf -interaction=nonstopmode -halt-on-error`, then `latexmk -c` to remove auxiliary files while keeping the PDF.

#### `texclean.sh`
Recursively deletes all LaTeX auxiliary files from the current directory tree:
`.aux`, `.bbl`, `.blg`, `.log`, `.out`, `.synctex.gz`, `.snm`, `.toc`, `.nav`

#### `init_cheatsheet.sh`
Rsyncs a LaTeX cheatsheet template from a hardcoded machine-specific path (`~/Documents/Templates/LaTeX Templates/Cheatsheet/`) into the current directory. Intended for quickly bootstrapping a new cheatsheet project.

## Installation Workflow

```bash
# 1. Configure paths in global_vars.py (edit _INSTALL_DIR / _DATA_DIR if needed)
python3 init.py

# 2. Install each tool independently
python3 open/install.py
python3 scripts/install.py

# 3. Reload shell
source ~/.bashrc
```
